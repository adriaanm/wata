# family 1, DM 2 — and leaves its session in $WATA_FB_CONFIG for phase 4 to
# resume. The waits walk the selection down to the DM and back so the probe
# (which reads the SELECTED conversation) sees both counts before the dump.
#
# quiet: priming happens on the first non-empty snapshot, so a backlog that
# syncs in across two snapshots would count its tail as an arrival — and
# play mode would auto-play and RECEIPT it, dropping a badge this phase's
# golden pins (observed once under full-ci load: the Alice row read 1, not
# 2). See bob-dm-roundtrip.txt.
notifymode quiet

wait syncing 1 900
# [Family, Alice-DM]
wait convs 2 900

# rolodex physics: the impulse has to coast a detent and the pump write the
# new centre into the selection before anything acts on it

waitmax motionlive 0 90
wait msgs 2 2000
tap up
waitmax motioncentre 0 90
waitmax motionlive 0 90
# gate on the summed badge state itself (family 1 + DM 2), then outlast any
# quiet banner a raced arrival raised; both are 0-frame no-ops normally.
